### 🦉 About the Project
`treat_a_kuma` is a research initiative by Kuma-DoTech. In Indonesia, we call this "Traktir" — a way to support the creator if you find value in the work. These tools are built to help you understand your digital footprint in an increasingly tracked world.

### 🚀 Featured Tool: Kuma-Scan
A local audit utility to visualize how your browser is "stamped" by modern tracking platforms.
- **Transparency:** See what they see (Canvas hashes, Font enumeration, Timezone leaks).
- **Local First:** All processing happens on your machine.
- **Privacy Engine:** Compare identity persistence between Chromium and Gecko.
